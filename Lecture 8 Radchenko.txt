---1. Чем World Space отличается от Screen Space?

World Space — режим Canvas, при котором интерфейс располагается непосредственно в трёхмерном пространстве сцены. Панель имеет реальные координаты, размер и положение относительно объектов. В VR её можно разместить, например, рядом со станком.

Screen Space — режим, при котором интерфейс отображается относительно экрана камеры и не зависит от положения объектов в виртуальном мире. Он используется для обычных экранных меню и HUD.

Главное отличие: World Space предназначен для размещения интерфейса в 3D-сцене, а Screen Space — для отображения интерфейса на экране пользователя.


---2. Как размер и положение панели влияют на читаемость?

Размер панели определяет удобство восприятия текста и элементов управления. Слишком маленькая панель затрудняет чтение, а слишком большая может закрывать обзор.

Положение панели влияет на угол обзора, расстояние до пользователя и удобство взаимодействия. В VR интерфейс рекомендуется размещать на комфортном расстоянии перед пользователем, избегая резких поворотов головы и необходимости приближаться к нему.


---3. Как связать Button.onClick с методом клиента?

Для этого необходимо:
1. Создать кнопку Button в Canvas.
2. Создать C#-скрипт с методом, который должен выполняться при нажатии.
3. Добавить скрипт на объект сцены.
4. В компоненте Button найти раздел On Click().
5. Перетащить объект со скриптом в поле события.
6. Выбрать нужный публичный метод из списка.
Пример:
using UnityEngine;

public class MachineClient : MonoBehaviour
{
    public void StartMachine()
    {
        Debug.Log("Станок запущен!");
    }

    public void StopMachine()
    {
        Debug.Log("Станок остановлен!");
    }
}


После настройки кнопка будет вызывать соответствующий метод при нажатии.


---4. Как передать поля MachineState в TextMeshPro?

Для отображения данных из класса MachineState необходимо получить значения его полей и присвоить их свойству text компонента TextMeshProUGUI.

Пример:
using UnityEngine;
using TMPro;

[System.Serializable]
public class MachineState
{
    public float x = 30;
    public float y = 0;
    public float z = 60;
    public string status = "Работает";
}

public class MachineUI : MonoBehaviour
{
    public MachineState machineState;

    public TMP_Text coordinatesText;
    public TMP_Text statusText;

    private void Update()
    {
        coordinatesText.text =
            $"X: {machineState.x} мм\n" +
            $"Y: {machineState.y} мм\n" +
            $"Z: {machineState.z} мм";

        statusText.text = "Состояние: " + machineState.status;
    }
}


В Inspector необходимо назначить соответствующие текстовые объекты TextMeshPro.

В результате интерфейс будет отображать текущие координаты и состояние станка. При изменении полей MachineState текст будет обновляться автоматически.
