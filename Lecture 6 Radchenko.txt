----Движение узлов

1. Как назначить узлы X/Y/Z в Inspector?

Для назначения узлов необходимо создать три отдельных объекта (например, пустых GameObject) и назвать их X, Y и Z. Затем открыть объект, на котором находится управляющий скрипт, найти соответствующие поля в компоненте Inspector и перетащить в них нужные объекты из Hierarchy.

Если поля имеют тип `Transform`, Unity автоматически сохранит ссылки на координаты и положение назначенных объектов.


2. Зачем хранить начальные положения и использовать localPosition?

Начальные положения сохраняются для того, чтобы объект всегда мог вернуться в исходную точку или перемещаться относительно первоначальной позиции.

`localPosition` определяет положение объекта относительно его родительского объекта, а не относительно всей сцены.

Это особенно полезно при работе с иерархией объектов, поскольку позволяет перемещать узлы независимо друг от друга, сохраняя правильное взаимное расположение.


3. Куда направлены Vector3.forward и Vector3.up в Unity?

В Unity используются следующие направления координатных осей:

- `Vector3.forward` — направление вдоль положительной оси Z (вперёд).
- `Vector3.up` — направление вдоль положительной оси Y (вверх).
- `Vector3.right` — направление вдоль положительной оси X (вправо).

Эти векторы часто применяются для перемещения, вращения и определения направления движения объектов.


4. Почему повторный ответ не добавляет новое смещение?

Чтобы повторный ответ не увеличивал смещение объекта, необходимо рассчитывать его положение относительно сохранённой начальной позиции, а не прибавлять новые координаты к текущему положению.

Например, если каждый раз использовать `transform.position += offset`, смещение будет накапливаться. Если же использовать `initialPosition + offset`, объект будет перемещаться в заданную точку независимо от количества полученных ответов.


----Обмен данными


1. Какую роль выполняет Unity в клиент-серверной схеме?

Unity выступает в роли клиента, который отправляет запросы серверу, получает от него данные и отображает их в интерфейсе или использует для управления объектами сцены.

Сервер обрабатывает запросы, получает или формирует необходимые данные и возвращает ответ клиенту. Таким образом, Unity отвечает за визуализацию и взаимодействие с полученной информацией.


2. Какой HTTP-метод использует CncJsonController?

Если `CncJsonController` предназначен для получения данных от сервера, обычно используется HTTP-метод GET.

Он позволяет отправить запрос на сервер и получить информацию в формате JSON без изменения данных на сервере.

Примечание: точный метод зависит от реализации контроллера. Если в коде используется атрибут `[HttpGet]`, значит применяется GET.


3. Как найти координату X внутри массива data?

Если сервер возвращает данные в формате JSON, координату X необходимо найти внутри массива `data`, обратившись к соответствующему элементу и его свойству.

Например, если структура ответа выглядит так:

```
{
  "data": [
    {
      "axis": "X",
      "value": "125 мм"
    },
    {
      "axis": "Y",
      "value": "80 мм"
    }
  ]
}
```

Сначала необходимо обратиться к массиву `data`, затем найти элемент, у которого `axis` равен `"X"`, и получить его значение через поле `value`.


4. Зачем удалять «мм» и заменять запятую точкой?

Это необходимо для правильного преобразования полученного значения в числовой формат.

- Удаление `"мм"` убирает текстовое обозначение единицы измерения, которое мешает преобразованию строки в число.
- Замена запятой точкой приводит десятичный разделитель к формату, который ожидает стандартный парсер чисел при использовании соответствующей культуры.

Например, строка `"125,5 мм"` после обработки превращается в `"125.5"`, которую можно преобразовать в числовой тип `float`.

Для этого в C# можно использовать методы `Replace()` и `float.Parse()`.
