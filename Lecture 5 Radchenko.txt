1. Что такое ключи в контексте анимации?

Ключи (Keyframes) — это специальные точки на временной шкале анимации, в которых задаются значения определённых параметров объекта.

Например, при анимации перемещения куба можно задать:

- первый ключ — куб находится в начальной точке;
- второй ключ — куб переместился на 5 метров вправо;
- третий ключ — куб вернулся в исходное положение.

Unity автоматически рассчитывает промежуточные значения между ключами, благодаря чему создаётся плавное движение. С помощью ключей можно анимировать положение, вращение, масштаб, цвет и другие свойства объекта.


2. Отличие компонентов Animator и Animation

Animator и Animation — это компоненты Unity, предназначенные для работы с анимацией, но выполняющие разные задачи.

- Animator — компонент, который управляет воспроизведением анимаций через систему Animator Controller. Он позволяет переключаться между различными состояниями анимации, например ходьбой, бегом, прыжком и бездействием. Для переходов можно использовать условия и параметры.
- Animation — компонент, предназначенный для непосредственного воспроизведения анимационных клипов. Он относится к более старой системе анимации Unity и позволяет запускать отдельные анимации без использования Animator Controller.

Таким образом, Animator применяется для управления сложными последовательностями анимаций, а Animation подходит для более простого воспроизведения отдельных клипов.


3. Что такое скелет в контексте анимации?

Скелет (Rig) — это система взаимосвязанных виртуальных костей, которая используется для управления движениями трёхмерного персонажа.

Каждая кость отвечает за движение определённой части модели: руки, ноги, головы, туловища и других элементов. Кости соединены между собой и образуют иерархическую структуру.

При вращении или перемещении одной кости связанные с ней части модели также изменяют своё положение. Это позволяет создавать естественные движения персонажа: ходьбу, бег, прыжки, повороты головы и движения конечностей.

Скелет особенно важен при анимации персонажей, поскольку позволяет управлять моделью без необходимости изменять положение каждой её части вручную.
