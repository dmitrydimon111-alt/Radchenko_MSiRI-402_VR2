Часть 1



1. Чем класс отличается от объекта?

Класс — это шаблон или описание, по которому создаются объекты. Он определяет свойства (поля) и действия (методы), которые будут доступны объектам данного класса.

Объект — это конкретный экземпляр класса, созданный в программе. Каждый объект имеет собственные значения полей и может выполнять методы, определённые в классе.

Например, класс «Автомобиль» описывает общие характеристики автомобиля: марку, цвет и скорость. Объекты этого класса — конкретные автомобили с определёнными значениями этих характеристик.

2. Что хранит переменная класса?

Переменная класса хранит ссылку на объект, созданный на основе данного класса, а не сам объект целиком. С помощью этой ссылки программа может обращаться к полям и методам объекта.

Например, если переменная `car` ссылается на объект класса `Car`, то через неё можно получить марку автомобиля или вызвать метод для изменения его скорости.

3. Что произойдёт при обращении к члену через null-ссылку?

Если попытаться обратиться к полю или методу объекта через ссылку со значением `null`, произойдёт ошибка выполнения программы.

В языке C# такая ошибка называется `NullReferenceException`, а в Java — `NullPointerException`.

Это происходит потому, что ссылка `null` не указывает ни на один существующий объект, поэтому программа не может получить доступ к его полям или методам.

4. Зачем объединять поля и методы в одном классе?

Поля и методы объединяют в одном классе для организации данных и действий, которые относятся к одному объекту. Такой подход называется инкапсуляцией.

Это позволяет:
- Объединять характеристики объекта и операции над ними.
- Упрощать структуру и понимание программы.
- Защищать данные от неправильного изменения.
- Повторно использовать код и упрощать его сопровождение.

Например, класс «Автомобиль» может содержать поле `speed` (скорость) и методы `Accelerate()` (ускорение) и `Brake()` (торможение). Таким образом, данные автомобиля и действия над ними находятся в одном месте.



Часть 2

# Вопросы для самопроверки

1. Зачем скрывать поля класса?

Поля класса скрывают для защиты данных от прямого и неконтролируемого изменения извне. Это позволяет ограничить доступ к внутреннему состоянию объекта и предотвратить присвоение некорректных значений.

Для этого используют модификаторы доступа, например `private`. Изменять и получать значения таких полей можно через специальные методы или свойства класса. Такой подход называется инкапсуляцией.

2. Чем свойство отличается от поля?

Поле — это переменная, которая непосредственно хранит данные внутри класса.

Свойство — это специальный механизм доступа к данным, который позволяет получать и изменять значения полей с помощью методов `get` и `set`.

Главное отличие заключается в том, что поле хранит значение, а свойство контролирует доступ к нему. Например, свойство может проверять корректность вводимых данных перед их сохранением.

3. Что произойдёт, если не объявить ни одного конструктора?

Если в классе не объявить ни одного конструктора, компилятор автоматически создаст стандартный конструктор без параметров (в C# — конструктор по умолчанию).

Он позволит создавать объекты класса без передачи дополнительных аргументов. Поля объекта при этом получат значения по умолчанию, соответствующие их типам.

4. Как конструктор связан с инкапсуляцией?

Конструктор связан с инкапсуляцией тем, что позволяет устанавливать начальные значения полей объекта при его создании и контролировать правильность этих значений.

Например, конструктор может проверять, чтобы возраст человека не был отрицательным. Это помогает защитить внутренние данные объекта от некорректного состояния.

Таким образом, конструктор обеспечивает правильную начальную инициализацию объекта и поддерживает принципы инкапсуляции.

5. Можно ли изменить свойство только для чтения после создания объекта?

Всё зависит от способа объявления свойства.

В C# свойство с модификатором `private set` можно изменять только внутри самого класса, а свойство с `get` без `set` доступно только для чтения извне.

Если используется свойство `init`, его можно установить при создании объекта, но нельзя изменять обычным способом после завершения инициализации.

Таким образом, возможность изменения свойства зависит от используемых методов доступа (`get`, `set`, `init`) и ограничений, установленных в классе.
